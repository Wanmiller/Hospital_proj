# Пациент интерфейсі

Скриншоттар бөлек тест базасында, жасанды «Айдана Тест» аккаунтымен түсірілген.

- `registration.png`, `registration-mobile.png` — тіркелу.
- `booking.png`, `booking-mobile.png` — дәрігер мен бос уақытты таңдау.
- `appointments.png`, `appointments-mobile.png` — жеке қабылдаулар.
- `verification.json` — браузерлік тексеріс нәтижелері.

Толық нұсқаулық: [Пациент рөлі](../patient-role.md).
