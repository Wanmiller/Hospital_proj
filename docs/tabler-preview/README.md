# Tabler интерфейсінің көріністері

Барлық скриншоттар жеке `hospital_regression_tabler` тестілік базасында алынған. Атаулар, көрсеткіштер және қабылдаулар — браузерлік тексеруге арналған оқу деректері. Жұмыс базасына тестілік өзгерістер енгізілген жоқ.

- `login.png`, `login-mobile.png` — ықшам кіру формасы.
- `admin.png`, `admin-mobile.png` — әкімші кабинеті.
- `reception-day.png`, `receptionist-mobile.png` — тіркеушінің күндік қабылдаулары.
- `doctor-day.png`, `doctor-mobile.png` — дәрігердің жеке күндік қабылдаулары.
- `patient.png` — пациент картасы.
- `consultation.png` — қабылдау және медициналық жазба.
- `reports.png` — қолданыстағы есептер.
- `verification.json` — браузерлік тексерулердің тізімі мен нәтижелері.

Іске асыру: Tabler Core 1.7.1, жергілікті SVG Tabler Icons, ортақ қазақша сөздік. Браузерде сыртқы CSS, JavaScript немесе қаріп сұраныстары жоқ.
