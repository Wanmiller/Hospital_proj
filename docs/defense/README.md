# 15 минуттық қорғау: екі адам

Негізгі жоспар: әр адамға 6 минуттан, сұрақтарға 3 минут. Материал қазақ тілінде, жобаның қазіргі кодына сәйкес дайындалған.

## DeckCraft презентациясы

- [Жаңартылған материалдардың ZIP архиві](deckcraft/Emhana_deckcraft_v2.zip) — презентация мен екі адамға арналған жоспарды бірге жүктеу.
- [Жаңартылған PPTX: 13 слайд](deckcraft/Emhana_prezentatsiya_v2.pptx) — DeckCraft немесе PowerPoint бағдарламасында ашыңыз.
- [Жаңартылған DeckCraft жобасы](deckcraft/Emhana_prezentatsiya_v2.deckcraft) — бағдарламаның өз форматы.
- [Жаңартылған PDF нұсқасы](deckcraft/Emhana_prezentatsiya_v2.pdf) — қосымша көрсету нұсқасы.
- [13 слайдқа арналған сөйлеу жоспары](deckcraft/soileu-zhospary.md) — екі адамның реті мен 15 минуттық уақыт бөлінісі.

Бұл презентацияда баяндамашылардың белгілері мен қорғаныс уақыты көрсетілмейді. Төмендегі материалдар — бұрынғы 10 слайдтық нұсқа және қосымша сұрақ-жауап.

| Файл | Қалай пайдалану керек |
|---|---|
| [Барлық материал ZIP](defense-materials.zip) | Екінші компьютерге жүктеп, архивті толық шығару |
| [Сөйлеу мәтіні және нұсқаулық](guide-kk.md) | Екі адамның мәтіні, тайминг, көрсетілім, 22 сұрақ-жауап, SQL және код картасы |
| [Word нұсқасы](guide.docx) | Аты-жөндеріңізді қосу және мәтінді өзгерту |
| [Басып шығару PDF](guide.pdf) | 11 беттен тұратын толық нұсқаулық |
| [Слайдтар HTML](slides.html) | Жүктеп, браузерде жергілікті ашу; 10 слайд |
| [Слайдтар PDF](slides.pdf) | Интернетсіз көрсетуге арналған қосымша нұсқа |
| [Бір беттік жадынама](cheatsheet.pdf) | Қорғау кезінде өздеріңізге арналған қысқа тірек |
| [Жадынаманың мәтіні](cheatsheet.md) | Телефоннан немесе GitHub арқылы оқу |
| [Тексеру нәтижесі](verification.json) | PDF беттері, слайдтардың сыйымдылығы, сыртқы сұраулар |

HTML слайдтарында ←/→ — ауысу, `F` — толық экран, `N` — баяндамашы ескертпелері, Home/End — басы/соңы. GitHub-тағы HTML беті бастапқы код түрінде көрінеді: браузерде көрсету үшін ZIP-ті жүктеп, шығарып, `slides.html` файлын ашыңыздар. Архивтегі `images` бумасын қасында сақтаңыздар.

Көрсетілім үшін сайтты `guide-kk.md` ішіндегі нұсқаулықпен бөлек `hospital_defense_demo` базасында іске қосыңыздар. Архивтің өзі сайттың PHP сервері немесе базасы емес.

Слайдтағы скриншоттар — бөлек тест базасында жасанды деректермен бұрын түсірілген экрандар. Браузерлік тест сандары 27.10.2026 күнгі сақталған JSON нәтижелерінен алынған. Бұл материалды құрастыруда жұмыс базасы өзгертілген жоқ.

Қайта құрастыру: `python docs/defense/build.py`. Генераторға Python пакеттері `python-docx`, `markdown`, `playwright`, `pypdf` және Playwright Chromium қажет; олар қолданбаның runtime тәуелділіктері емес.
