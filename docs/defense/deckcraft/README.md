# Емхана жобасын қорғау: DeckCraft презентациясы

Жаңартылған презентация 13 слайдтан тұрады; слайдтарда баяндамашы белгілері мен қорғау уақыты көрсетілмейді. Рөлдер кестесі, байланыстар сызбасы, уақыт қақтығысының мысалы және SQL сұрауы қосылған.

- `Emhana_prezentatsiya_v2.deckcraft` — DeckCraft-та өңделетін жаңартылған файл.
- `Emhana_prezentatsiya_v2.pptx` — жаңартылған PPTX презентациясы.
- `Emhana_prezentatsiya_v2.pdf` — жаңартылған PDF нұсқасы.
- `Emhana_deckcraft_v2.zip` — жаңа презентация және сөйлеу материалдары бір архивте.
- `soileu-zhospary.md` — екі адамға арналған 15 минуттық сөйлеу жоспары. 13 слайдтың реті екі нұсқада да бірдей.

Бастапқы нұсқалар да осы бумада сақталған:

- `Emhana_prezentatsiya.deckcraft` — DeckCraft-та өңделетін бастапқы файл.
- `Emhana_prezentatsiya.pptx` — DeckCraft пен PowerPoint-та ашылатын презентация.
- `Emhana_prezentatsiya.pdf` — көрсетілімнің PDF нұсқасы.
- `Emhana_deckcraft_materialdary.zip` — осы файлдар мен толық сұрақ-жауап материалы бір архивте.

Қабылдауға жазылу және дәрігер беттерінің суреттері — бөлек тест базасында жасанды деректермен түсірілген скриншоттар. Слайдтардағы мәтіндер мен диаграммалар өзгертуге болады.

Дереккөздегі `build_presentation_v2.py` жаңартылған презентацияны DeckCraft 0.10.0 CLI арқылы құрастырады. Жұмыс істету үшін файлдағы CLI жолын өз компьютеріңіздегі DeckCraft орналасуына сәйкестендіріңіз.
