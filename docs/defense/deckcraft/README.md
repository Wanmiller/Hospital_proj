# Емхана жобасын қорғау: DeckCraft презентациясы

Презентация 13 слайдтан тұрады; слайдтарда баяндамашы белгілері мен қорғау уақыты көрсетілмейді.

- `Emhana_prezentatsiya.deckcraft` — DeckCraft-та өңделетін бастапқы файл.
- `Emhana_prezentatsiya.pptx` — DeckCraft пен PowerPoint-та ашылатын презентация.
- `Emhana_prezentatsiya.pdf` — көрсетілімнің PDF нұсқасы.
- `soileu-zhospary.md` — екі адамға арналған 15 минуттық сөйлеу жоспары.
- `Emhana_deckcraft_materialdary.zip` — осы файлдар мен толық сұрақ-жауап материалы бір архивте.

Қабылдауға жазылу және дәрігер беттерінің суреттері — бөлек тест базасында жасанды деректермен түсірілген скриншоттар. Слайдтардағы мәтіндер мен диаграммалар өзгертуге болады.

Дереккөздегі `build_presentation.py` презентацияны DeckCraft 0.10.0 CLI арқылы құрастырады. Жұмыс істету үшін файлдағы CLI жолын өз компьютеріңіздегі DeckCraft орналасуына сәйкестендіріңіз.
