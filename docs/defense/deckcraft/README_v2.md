# Жаңартылған презентация

- `Emhana_prezentatsiya_v2.deckcraft` — DeckCraft бағдарламасында ашылып, өңделеді.
- `Emhana_prezentatsiya_v2.pptx` — DeckCraft немесе PowerPoint бағдарламасында ашылады.
- `Emhana_prezentatsiya_v2.pdf` — көрсетілімге арналған PDF.
- `soileu-zhospary.md` — екі адамға арналған дайындық жоспары.
- `../guide-kk.md` — кеңейтілген сұрақ-жауап және базаны іске қосу нұсқаулығы.

Презентацияда 13 слайд бар. Екі адамға арналған белгілер тек бөлек сөйлеу жоспарында берілген.
