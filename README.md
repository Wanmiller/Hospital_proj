# Емханадағы қабылдауға жазылу жүйесі

PHP және MySQL/MariaDB негізіндегі оқу жобасы. Интерфейс қазақ тілінде, Tabler Core 1.7.1 файлдары жергілікті сақталған.

## Мүмкіндіктер

- **Пациент:** тіркелу, бос уақытқа жазылу, өз қабылдауларын көру және жоспарланған жазылудан бас тарту.
- **Тіркеуші:** пациент карточкалары, қабылдауға жазу, жазбаны өзгерту және болдырмау.
- **Дәрігер:** жеке қабылдаулар, медициналық жазбалар, рецепттер және өз пациенттерінің тарихы.
- **Әкімші:** пайдаланушылар, дәрігерлер, бөлімшелер және есептер. Бұрынғы пациент карточкасына жеке аккаунт байланыстыру.

Дерекқор бір дәрігердің бір уақытына қос жазылуды шектейді. Аяқталған немесе медициналық жазбасы бар қабылдауды болдырмауға болмайды. Пациент тек өз қабылдауларына қол жеткізеді.

## Жергілікті іске қосу

PHP 8.2, `pdo_mysql`, `mbstring`, MySQL немесе MariaDB қажет. HTTP тесттер үшін PHP `curl` кеңейтімі пайдаланылады. Windows-та XAMPP жарайды.

1. Репозиторийді көшіріңіз және MySQL қызметін іске қосыңыз:

   ```powershell
   git clone https://github.com/Wanmiller/Hospital_proj.git
   cd Hospital_proj
   ```

2. Қажет болса, база параметрлерін орта айнымалылары арқылы беріңіз: `HOSPITAL_DB_HOST`, `HOSPITAL_DB_USER`, `HOSPITAL_DB_PASS`, `HOSPITAL_DB_NAME`. Жергілікті әдепкі мәндер — `localhost`, `root`, бос құпиясөз және `hospital_db`. Жеке құпиясөздерді репозиторийге қоспаңыз.

3. Жаңа бос база мен кестелерді жасаңыз:

   ```powershell
   & D:\xampp\php\php.exe setup_db.php
   ```

   Жаңа орнатуда әкімші — `admin` / `admin123`, тіркеуші — `reception` / `rec123`. Бұл — оқу ортасына арналған бастапқы аккаунттар; құпиясөздерін әкімші бөлімінде өзгертіңіз. Пациент `register.php` бетінде тіркеледі. Дәрігер аккаунтын әкімші жасайды.

4. PHP серверін іске қосыңыз:

   ```powershell
   & D:\xampp\php\php.exe -S localhost:8000 -t .
   ```

5. Браузерде [http://localhost:8000](http://localhost:8000) ашыңыз.

Бұрыннан бар базаны жаңарту алдында SQL сақтық көшірмесін жасап, `php database/upgrade.php` орындаңыз. `database/hospital.sql` — демонстрациялық толық импорт: басында базаны жояды, сондықтан оны жұмыс базасына импорттамаңыз.
